Rwanda Landslide Susceptibility Mapping

Research code for journal peer review

This repository contains the Python/ArcPy implementation associated with the research manuscript entitled “An Automated Python-Based Logistic Regression Tool for National-Scale Landslide Susceptibility Mapping.”

The repository is provided to support editorial assessment, peer review, and evaluation of the computational workflow underlying the research.

Manuscript status: Prepared for journal submission / under review, as applicable.

The code implements the research workflow described in the manuscript. The scientific methods, equations, and model settings should be interpreted in conjunction with the manuscript.

Software requirements

ArcGIS Pro with a compatible ArcPy environment

ArcGIS Spatial Analyst extension

NumPy, pandas, SciPy, and Matplotlib, as required by the script

Data availability

The workflow uses raster predictor datasets, landslide training samples, validation samples, and associated geospatial inputs. Some datasets may be subject to third-party licensing, institutional access restrictions, or file-size limitations.

Datasets that cannot be redistributed publicly are not included in this repository. Their sources, access conditions, and any reviewer-access arrangements should be documented in the accompanying data inventory.

Reproducibility

The repository includes the research script and documentation of the required inputs and software environment. Successful execution requires access to the necessary geospatial datasets, compatible ArcGIS Pro software, and the appropriate Spatial Analyst licence.
